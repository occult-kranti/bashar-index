# Transcription progress: archived latest-20 recordings

Speech-to-text of the archived recordings that had no transcript yet: 1,729 audio files, 746.3 hours, on
one local GPU. The run started on 20 November 2026 and finished at 19:56 UTC; the 30 recordings whose audio
could not be downloaded are not part of it. Rows were added as the run went, about every 100 audio files.

Times are UTC. The table counts audio files, as it did during the run; hours are of audio. Only counts are
published here; transcripts stay in the private archive. Two columns that the table carried during the run are
left out. The hours without speech were measured on every creator's audio, and timing measures are now reported
for the creators seen before the registry freeze only (the run report gives them). The number of languages found
so far rose in a row only when the first recording of a language that fewer than 5 creators speak was done.
At the finish 7 languages had been found; the run report gives English and the other languages pooled.

The number of recordings held back is not given row by row: the run's records hold no time at which a hold
began or ended, so the creators behind an earlier row's count cannot be counted, and no row can be shown to
rest on 5 or more creators. At the finish 32 recordings were not transcribed, by the reasons
of the run report's outcome table: 19 "No speech found in the whole recording" and 13 "Held back for another reason".
Each of these rows holds recordings of 5 or more creators; the outcome table pools the reasons that concern
fewer.
