      How to read this index

      “Listed uploads” means a channel’s uploads were read during the original indexing pass. “Research notes” means metadata was recorded without that crawl. Neither is a statement about current availability.

      Relative upload dates, view counts and subscriber totals belong to the original observation. Empty fields are unknown. Rows without a recorded video ID remain visible as part of the original sample.

      This page uses public metadata only. Recordings, full transcripts and private contact details are not included.
