# Discovery table: channelers and claimed sources

This batch contains **115 sourced relationship records for 28 people**, plus the explicitly requested Multidimensional Soul host shown separately below. It is a discovery batch, not an exhaustive table of the current 109 project profiles (108 before the requested host was registered). Inclusion does not automatically add a candidate to download queues.

These are self-reported relationships attributed to primary sources. The table does not independently establish the claimed beings, historical narratives or healing effects; no medical efficacy claims are endorsed. **Attributed channeling does not, by itself, establish a conventional-language spoken performance.** Written material, event listings, light language, reported contact and guide associations remain distinct.

The parent independently opened all 30 primary relationship-source pages and accepted the attributed relationships for all 115 records; see the [source-review audit](parent-source-review.json) and [normalized CSV](discovery-relationships.csv). This acceptance verifies source attribution, not the claimed beings or actual speech samples. Ownership remains a separate check: an own-channel link is evidence of attribution, while a guest appearance is insufficient. Five handle/custom-URL destinations still require canonical-ID resolution before new registry insertion.
