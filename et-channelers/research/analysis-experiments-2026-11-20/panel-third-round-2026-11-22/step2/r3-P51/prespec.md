## 2. Rows per computed class (programme: unmatched, position-matched, middle-model)

On the voice-eligible creators (shared 0.1), per creator: claimed-voice and own-voice counts and tokens.
- **Unmatched**: per creator, log((claimed hits + 0.5) / claimed tokens) - log((own hits + 0.5) / own tokens); the creator
  mean with r3-P30's design class H interval at the eligible count. Beside it, r3-P42's creator-balanced voice log ratio
  against its matched-placebo band.
- **Position-matched**: within creator and recording tenth, own-voice counts re-weighted to the claimed voice's token
  distribution over tenths, using only tenths where both voices have tokens: expected own count = sum over tenths of
  claimed tokens x own rate in that tenth; per creator log((claimed hits + 0.5) / claimed tokens) - log((expected own count
  + 0.5) / claimed tokens), over the same tenths; class H interval.
- **Middle-model**: the unmatched row with sides from the middle model's rule-B labels (own voice broad, claimed V2 + V3,
  claimants sole speaker or host), on recordings the middle model labelled in full; eligibility as 0.1 under those sides.
- Margin 0.223; no direction deposited (the three-way prediction table, meaning / news hook / attribution shield, was not
  deposited before any count, so it is "not scored"). Words: "beyond the margin (claimed higher)", "beyond the margin
  (own higher)", "within the margin (B)", "undetermined". If the rows disagree: "undetermined (rows disagree)".
- **By stratum composition**: the same unmatched row inside each title-profile stratum (CSS-5: star against angelic or
  devotional), only where each stratum holds 5 or more voice-eligible creators.

## 3. The model-free named-actor proxy (T190)

The register's pattern row: runs of two or more capitalised, not sentence-initial tokens (the recognizer's capitalisation),
minus runs holding an L01 S14 or L04 name form, from r3-P42's extract (per-token mask). A hit is one run (runs split at
unit boundaries). It is not a list class, so the thin rule does not apply; it needs 5 or more creators carrying hits on
each side. Rows: unmatched, position-matched and middle-model, as section 2. It is printed only as aggregate rates and
contrasts: no run, name or person is ever printed or stored outside `private/` (counts only are stored).
