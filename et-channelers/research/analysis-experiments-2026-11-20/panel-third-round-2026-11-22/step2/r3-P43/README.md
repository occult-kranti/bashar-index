# r3-P43 / r4-P26: co-presence of historically dated vocabularies, by voice (step 2 of the third-round panel programme)

Run on 2026-11-26 (UTC, every time from `date -u`) by the step-2 description agent for r3-P43, r3-P44, r3-P45 and r3-P46
(a model agent working for the project lead; not a person), after deposit 3 (merged 2026-11-26T11:14:53Z) and r3-P42.
This folder carries **r4-P26** (novelty log N25).

**Exploratory; not a test of H1-H10.** Tier L: the 23 non-development seen creators (deposit 2's split), run once with no
split; voice statistics on the 11 voice-eligible creators of r3-P42. Every count is a cue count: sense not resolved,
precision unknown, until a reader is funded. Voice labels are model-coded and not checked by a person; agreement between
instruments is agreement, never accuracy. Wording: the speech **draws on vocabulary first current in period X**, never
descent; "imported" never judges sincerity. A reading is a description, never a finding.

> No measure in this study can tell whether a non-human source speaks; every measure describes the speech in these
> recordings and how the creators present it.

## Privacy

Every printed value rests on 5 or more creators who carry it; otherwise "not printed". The creator counts printed are the
23 non-development creators and the 11 voice-eligible creators (both printed by deposit 2 and r3-P42); layer users and
R11's occurrence are printed only as bands of the 23. No per-creator row or point, no quantile of creator values, no
group size or group mean. Terms are named only from the deposited lists and only where 5 or more creators use them.
Intervals: r3-P30's choice at the exact count 11 (t interval) or fixed-method bands. Before finishing, the identifier
scan, zsolve, qscan_all2, whole_position_scan and the s1_* solvers (s1_blanks with `d62`) were run (status.json); 0 rows
pinned or narrowed, no leak, 0 identifier hits.
