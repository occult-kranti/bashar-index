## Method

Before any set was computed, each row's voice-eligible rule (which labels, which threshold of tokens or seconds per voice
side, which recordings, which creators) was written into a private prespecification and hashed with its time. Where the
registration and the programme left a choice open, the rule the third panel used for the same kind of row was taken. Each
set was then computed from model-coded labels (tokens per voice side, span interiors, block counts, recording kinds, the
presence of an ask class, and the audio pass's recording gate) and set memberships only; no contrast outcome and no list
count was read. Each set was compared with the printed creator groups whose memberships are stored: by membership where
two sizes lie 1 to 4 apart, by size where they differ by 5 or more, and by deduction for groups that lie wholly inside the
development creators, wholly inside the check creators, or among the hold-out creators. For f4-Q09 (vi), whose reading
set leaves out one half of deposit 2's split, the set was formed, and compared with deposit 2's sets by membership as well,
with the owner's approval; the project lead ran the process that read the split record, and nothing from that record is
printed. A row passes when, for every printed group, each of its sets is identical to it, is not nested with it, or lies
5 or more creators from it. Printed groups whose
memberships are not held in the stores read here were compared under the standing rule's scope: no statistic of the same
measure is printed on two printed groups nested within 1 to 4 of each other. A set that a later, registered restriction
narrows (a cue minimum, a thin rule, an exclusion, a match) is a new set: it is checked again by the same code before its
count is read, and its row prints only on a pass. Where two of this deposit's own rows of the same measure rest on sets
nested within 1 to 4 of each other, only the row on the standard voice-eligible set prints; the other reads "not printed
(privacy rule)".

No count, size, band or membership is printed here.
